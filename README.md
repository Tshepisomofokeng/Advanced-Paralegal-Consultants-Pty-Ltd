# Advanced Paralegal Consultants Website

Overview
This is the official website for Advanced Paralegal Consultants (Pty) Ltd.  
It provides information about paralegal services, contact options, and showcases the company’s expertise.

Features:
- Responsive design for all devices
- SEO-friendly structure
- Smooth scroll animations
- Contact form integrated with Netlify Forms
- Social media links
- Parallax/scroll reveal effects
- Counter animations for experience and stats
